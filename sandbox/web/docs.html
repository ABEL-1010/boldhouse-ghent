Atlas documentation: configuration

Atlas reads its configuration from environment variables at startup.

How do I configure the log level?

Set LOG_LEVEL to DEBUG, INFO (default) or WARNING, then restart the service.

How do I change the export schedule?

Set EXPORT_CRON to a cron expression. The default is 0 3 * * * (03:00 UTC every night).

How do I add a new product collector?

Create a module in atlas/collectors/ that implements collect() and register it in atlas/collectors/__init__.py.
